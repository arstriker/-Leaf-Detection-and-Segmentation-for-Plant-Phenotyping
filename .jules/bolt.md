## 2024-05-24 - Unintended Destructive Actions via Search and Replace
**Learning:** Overzealous or poorly scoped search-and-replace scripts (or `re.sub()`) meant to fix formatting or syntax errors often silently delete critical logic and variables (like `area_px`).
**Action:** When acting strictly as Bolt to implement performance optimizations, do not bundle unassigned fixes for preexisting merge conflicts unless specifically instructed. Use highly-targeted diff patches or exact string replacements exclusively for the optimization, even if the file fails `py_compile` due to pre-existing errors elsewhere.
