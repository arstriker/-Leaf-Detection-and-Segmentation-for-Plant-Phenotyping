## 2024-05-19 - NumPy Array Allocation and cv2.bitwise_and Memory Optimization
**Learning:** In NumPy/OpenCV image processing workflows, using `cv2.bitwise_and` followed by subset selection (`[mask > 0]`) creates a massive hidden memory footprint by unnecessarily allocating and zero-filling a full-sized intermediate image matrix. For large plant images, this wastes significant CPU cycles and RAM when extracting masked statistical features.
**Action:** When only computing statistical features from masked foreground regions, completely bypass OpenCV intermediate allocations. Instead, apply the boolean array mask directly to the source image matrix via native NumPy indexing (e.g., `image[:,:,0][mask > 0]`), which is significantly faster and uses a fraction of the memory footprint.
