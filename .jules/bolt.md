## 2024-05-24 - [Avoid Redundant Array Allocation via Boolean Indexing]
**Learning:** [Allocating full-sized intermediate image arrays using functions like `cv2.bitwise_and(image, image, mask=mask)` just to immediately extract values using `array[mask > 0]` is a common computer vision anti-pattern in Python that wastes significant CPU cycles and memory bandwidth. Direct boolean indexing `image[mask > 0]` is mathematically equivalent and substantially faster.]
**Action:** [When processing image arrays in Python, prioritize direct boolean mask indexing to slice arrays rather than relying on C-bound `bitwise` functions when the goal is to extract feature data rather than to render a visual output mask.]
